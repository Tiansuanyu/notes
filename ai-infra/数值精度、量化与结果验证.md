# 数值精度、量化与结果验证

视觉匹配中“连续张量误差如何变成离散索引和位姿差异”的例子见[从 MNN 到 LightGlue 与 LighterGlue](../slam/fundamentals/从MNN到LightGlue与LighterGlue.md)和[从 PyTorch 到 ONNX 与 RKNN](../robotics-systems/deployment/从PyTorch到ONNX与RKNN.md)。

精度格式决定数值怎样表示；量化进一步用离散整数格点近似浮点值。验证不能停在输出张量“看起来接近”，而要沿任务链检查哪些离散决策发生了变化。

## 1. 浮点格式与混合精度

FP32 有较宽的尾数和指数；FP16 节省存储与带宽，但指数范围较窄；BF16 保留与 FP32 相同的指数位数而减少尾数精度。混合精度让不同算子选择合适 dtype，训练中常用 loss scaling 避免 FP16 小梯度下溢。

低精度并不保证更快：设备要有对应 kernel，布局转换和 fallback 也可能抵消收益。数值稳定性还取决于归一化、累加精度和输入范围。

## 2. 线性量化

常见仿射量化为

$$
q=\operatorname{clip}\!\left(\operatorname{round}(x/s)+z,q_{min},q_{max}\right),
\qquad \hat{x}=s(q-z),
$$

其中 $s$ 是 scale，$z$ 是 zero-point。假设 INT8 对称量化取 $s=0.1,z=0$，则 $x=0.26$ 量化为 $q=3$，反量化为 $0.3$，误差为 $0.04$。若 $x=20$，还会被截断到 127，对应 $12.7$，此时误差来自范围饱和而非舍入。

per-tensor 共用一个 scale，简单但可能被离群通道支配；per-channel 为不同输出通道设 scale，通常更细致但依赖运行时支持。权重量化和激活量化应分开说明。

## 3. PTQ、校准与 QAT

PTQ 在训练后量化，校准数据用于估计激活范围；QAT 在训练中模拟量化误差，让参数适应离散化。校准集应覆盖部署域的亮度、纹理和输入范围，不是越多越自动正确。训练用 QLoRA 的 4-bit 冻结基座也不同于部署 INT8 PTQ，见 [LoRA 与 QLoRA](./参数高效微调LoRA与QLoRA.md)。

## 4. 从张量误差到定位决策

视觉定位可按四层验证：

1. 比较关键层输出的绝对/相对误差和余弦相似度；
2. 比较检索 Top-k 的交集与正确候选名次；
3. 比较关键点、匹配数、几何内点和 PnP 是否变化；
4. 在共同样本上比较接受、正确接受与危险误接受。

小的平均张量误差可能让阈值附近的描述子换序，进而改变候选和最终 Pose；反之，中间数值不完全一致也可能不改变任务结果。因此既不能只看 `allclose`，也不能只看平均成功率而忽略失败样本。

## 5. 量化验收记录

固定浮点基线、模型和输入，记录量化范围/粒度、校准集版本、fallback 算子、逐层误差、任务指标和延迟边界。定位地图还应记录特征版本：地图侧浮点特征与 Query 侧量化特征能否混用必须实测，不能由相同维度推断兼容。

所有结论都应限定在所测输入域、运行时和阈值内。量化误差没有天然的“安全上界”，更不能由单个余弦相似度阈值推导定位正确概率。
