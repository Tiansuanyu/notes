# 训练、推理与知识迁移

训练和推理可以调用同一个 `forward`，但它们保存的状态、执行的模式与期望产物不同。理解这些边界，才能判断“冻结模型”“自蒸馏”或“只做推理”到底省掉了什么。

## 1. 最小训练闭环

一次监督训练由前向、损失、反向和更新组成：

```python
model.train()
optimizer.zero_grad()
prediction = model(inputs)
loss = criterion(prediction, target)
loss.backward()
optimizer.step()
```

前向把输入映射为预测；损失把任务目标变成标量；反向计算梯度；优化器利用梯度及动量等状态更新参数。梯度累积时不会每个 micro-batch 都 `step()`，因此“执行了一次前向”不等于“更新了一次参数”。

推理通常写成：

```python
model.eval()
with torch.no_grad():
    prediction = model(inputs)
```

`eval()` 改变 Dropout、BatchNorm 等模块的运行行为，却不会关闭自动微分；`no_grad()` 不记录反向图，却不会自动切换模块模式。二者正交，验证时通常都需要。

## 2. 监督、自监督和教师—学生

- 监督学习的目标来自人工或传感器标签；
- 自监督从输入自身构造目标，例如遮挡 patch 预测或不同增强视图的一致性；
- 教师—学生描述信息流，教师目标可来自标签训练、EMA 参数、完整模型或昂贵离线流程；
- 蒸馏是让学生学习教师的输出、表示或行为，不等于简单复制权重。

DINOv2 的教师—学生训练用于学习可迁移视觉特征；DiffWAM 则把完成视频生成与几何重建得到的轨迹监督传给较短的运动读出链。二者都可称蒸馏，但监督对象和部署产物不同，具体机制分别见 [DINOv2 与视觉基础特征](../slam/learning-based/DINOv2与视觉基础特征.md)和[从视频世界模型到 WAM](../robotics-systems/world-models/从视频世界模型到WAM.md)。

## 3. 冻结、线性探测与微调

冻结参数是令其 `requires_grad=False`，优化器不再更新这些叶子张量。线性探测冻结骨干，只训练浅层任务头；全量微调更新骨干和任务头；参数高效微调在冻结基座旁加入少量可训练参数。

冻结不一定允许把整个骨干包在 `no_grad()` 中。若可训练 adapter 的输入或输出仍经过冻结层，并需要梯度沿这些运算传回 adapter，关闭整段计算图会切断梯度。是否能局部关闭，要按依赖图验证。

## 4. 训练状态与可复现产物

一份可继续训练的 checkpoint 往往包含：模型参数、优化器状态、学习率调度器、混合精度 scaler、迭代位置和随机状态。仅保存推理权重不足以保证从同一点继续训练。

推理制品则至少需要：权重、结构/导出图、预处理、输入输出语义、标签或描述子版本，以及运行时要求。对于视觉地图，模型版本变化可能使新 Query 特征与旧地图描述子不兼容，不能只比较网络是否能加载。

## 5. 怎样验证知识迁移

先把三个问题拆开：训练目标是否真的下降，梯度是否只到预期参数；学生在冻结验证集上是否保持任务质量；部署制品是否保持相同输入契约和输出行为。

训练损失低不证明跨域泛化；教师输出也不是真值。蒸馏只能传递教师链中可见的信息和偏差。对于定位与几何任务，还要回到[定位评估方法](../slam/data-evaluation/定位评估方法.md)检查参考资格、接受与正确。
