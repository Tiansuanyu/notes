# Robotics Systems Overview

这里记录感知、定位、规划与控制怎样通过明确契约组成可恢复、可观测的机器人系统；算法原理见 [SLAM](../slam/)，模型计算与导出见 [AI Infra](../ai-infra/)。

## 系统基础

- [机器人系统分层与数据流](./机器人系统分层与数据流.md)：从传感器到控制理解职责、频率与反馈。
- [坐标、时间戳与数据契约](./坐标、时间戳与数据契约.md)：定义跨模块 Pose、TF、时钟和版本语义。
- [ROS 2 的通信与执行机制](./ROS2通信与执行机制.md)：理解 topic、QoS、Executor、callback group 与生命周期。
- [定位状态机、误接受隔离与恢复](./定位状态机、误接受隔离与恢复.md)：把候选验证和已确认状态分开。
- [异步推理、轨迹交接与可观测性](./异步推理、轨迹交接与可观测性.md)：处理迟到结果、运动补偿和端到端追踪。

## 专题

- [端侧部署](./deployment/)：学习式视觉模块的系统接入、Python/C++/worker 边界、CPU/GPU/NPU 分工、RKNN、测量与诊断实践。
- [世界模型与学习式导航](./world-models/)：世界模型的系统边界，以及 DiffWAM 的轨迹提案与异步执行。

## 推荐顺序

按“分层与数据流 → 坐标时间契约 → ROS 2 执行 → 状态机 → 异步交接 → 部署”阅读；世界模型专题建立在这些系统基础之上。
