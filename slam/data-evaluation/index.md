# 数据与评估

这一组笔记关注如何留下可解释的数据、把已有录制转成冻结实验输入、构造相机参考，并用边界清楚的指标完成评价。

建议阅读顺序：

1. [数据采集与交付](./数据采集与交付.md)
2. [数据清洗与实验输入构建](./数据清洗与实验输入构建.md)
3. [从 LIO 轨迹到相机参考位姿](./从LIO轨迹到相机参考位姿.md)
4. [参考误差如何影响算法评估](./参考误差如何影响算法评估.md)
5. [定位评估方法](./定位评估方法.md)

其中参考位姿篇回答参考怎样生成，参考误差篇分析参考变化如何影响测量和算法结论，定位评估篇统一指标、样本集合与评估协议。
