# 参考误差如何影响算法评估

同一组视觉定位预测保持不变，只替换评分参考，为什么误差数值、阈值成功率甚至方法排名也会变化？因为评估程序直接看到的不是“算法相对真实世界的误差”，而是**预测与参考之间的差异**。只要参考不是无误差真值，这个差异就同时包含算法误差和参考误差。

本文回答参考误差怎样进入测量，以及怎样检验算法结论对参考设定是否稳定。参考位姿的生成链见[从 LIO 轨迹到相机参考位姿](./从LIO轨迹到相机参考位姿.md)，ATE、RPE、成功率和样本分母见[定位评估方法](./定位评估方法.md)。

## 1. 先区分真实误差、参考误差和测得残差

在一维或只考虑平移的简化模型中，令真实位置为 $x^*$：

$$
x_{pred}=x^*+e_{alg},
\qquad
x_{ref}=x^*+e_{ref}.
$$

评估程序计算的残差为：

$$
r_{meas}=x_{pred}-x_{ref}=e_{alg}-e_{ref}.
$$

这里有三个不同对象：

- $e_{alg}$：算法预测相对真实位置的误差；
- $e_{ref}$：参考相对真实位置的误差；
- $r_{meas}$：实际能够计算的预测—参考残差。

如果两种误差方向相同，测得残差可能因抵消而变小；方向相反时，残差会叠加。于是“相对参考更准”不必然等价于“相对真实位姿更准”。共同使用同一份参考只保证比较口径相同，并不能保证方法间差距或排名完全不受参考误差影响。

### 1.1 位姿不能直接逐元素相减

上面的加减法只用于建立直觉。旋转和平移组成 SE(3) 位姿，矩阵元素不在普通向量空间中。本文统一令 $T_{W\leftarrow C}$ 把相机坐标变到世界坐标；同一时刻的预测与参考可定义相对误差变换：

$$
E=T_{W\leftarrow C}^{ref\,-1}T_{W\leftarrow C}^{pred}.
$$

$E$ 的旋转部分可转换为旋转角，平移误差可以比较相机光心，或在明确坐标系后读取相对变换的平移。左扰动和右扰动表达的坐标不同，必须声明约定。完整坐标链和 raw/rectified 区分仍由参考位姿篇负责，这里不重复推导。

### 1.2 参考与算法误差可能相关

若 Reference 建图、Query 评分参考和被测算法共享图像、轨迹、外参、时间模型或优化目标，$e_{alg}$ 与 $e_{ref}$ 未必独立。例如，视觉地图和参考相机位姿共享同一组标定偏差时，某种算法可能更容易复现参考中的系统误差。

因此不能把两项方差默认相加，也不能因为参考残差变小就断言参考更接近真实位姿。残差变小可能来自真实改进、误差抵消、样本变化，或预测与参考共享偏差增强。

## 2. 不同参考误差会怎样改变指标

参考误差不会一对一决定某个指标的变化方向。影响取决于运动、空间位置、是否允许轨迹对齐、评价阈值、样本覆盖以及算法误差与参考误差的相关性。

| 参考误差 | 可能影响平移/旋转与阈值成功率 | 对 ATE、RPE 和方法差距的可能影响 |
| --- | --- | --- |
| 固定平移偏差 | 无对齐绝对位置整体偏移；阈值附近样本可能跨过成功边界 | 无对齐 ATE 增大；共同左乘平移在理想相对运动中可抵消，RPE 不一定变化 |
| 固定旋转偏差 | 姿态残差改变；离旋转中心越远，位置杠杆臂效应越明显 | SE(3) 对齐可能吸收全局旋转；无对齐 ATE 和绝对重定位误差可能随空间位置变化 |
| 时间偏移 | 速度和角速度把时间差转成位置、姿态差；静止段与快速运动段影响不同 | ATE 和 RPE 都可能受影响；重新关联后有效样本集合也可能改变 |
| 局部轨迹漂移或形变 | 不同区域、时段的偏差不同，单个刚体对齐无法全部消除 | ATE 的空间分布改变；RPE 取决于间隔和局部形变，方法差距可能随区域变化 |
| 错误的跨序列注册候选 | 整段参考落到错误房间或重复结构，可能出现大的公共偏差，也可能局部残差看似合理 | 所有方法都可能被同一错误世界变换影响；共同趋势是审计线索，不足以单独证明参考错误 |
| 建图与评分共享参数偏差 | Reference 地图几何和 Query 参考可能同时变化，误差可相关 | 某些方法可能因共享模型而更贴近参考；只扰动评分端无法表达完整端到端影响 |

### 2.1 坐标系变换、外参误差与错误参考对齐不是一回事

把同一组位姿从世界 W 表达到另一个世界 W'，如果预测与参考都正确应用同一已知刚体变换，只是**坐标表示改变**，不应被视为物理误差。

相机—LiDAR 外参错误会改变传感器轨迹到相机轨迹的转换，旋转与杆臂共同作用，属于参考生成链的物理参数误差。跨序列注册选错候选则是两个世界关系 $T_{W_r\leftarrow W_q}$ 错误。三者可能都表现为矩阵变化，但含义、作用位置和验证方法不同。

### 2.2 ATE 是否对齐决定哪些偏差会被消除

ATE 使用 SE(3) 对齐时，可以吸收一个全局旋转和平移；使用 Sim(3) 时还会吸收统一尺度。这样得到的是“消除这些自由度后的轨迹形状差异”，不是已知地图中未经修正的绝对定位误差。

若任务是已知地图重定位，用测试预测再次拟合自由变换可能把真正的全局位置错误消掉。相反，自由世界原点的 VO/VIO 轨迹不做允许的对齐，又会把纯 gauge 差异计入误差。对齐自由度必须由任务决定，不能根据哪一种结果更好再选择。

### 2.3 RPE 会抵消什么，又保留什么

对于相邻位姿的相对运动：

$$
\Delta T_{ij}=T_i^{-1}T_j.
$$

若所有参考位姿都被同一个固定世界变换 G 左乘，则

$$
(GT_i)^{-1}(GT_j)=T_i^{-1}T_j,
$$

这个共同 world 变换会在理想相对运动中抵消。但时间错位、随位置变化的漂移、非刚性地图形变不会作为同一个 G 抵消；外参误差通常作用在传感器链右侧，可能改变相对运动的表达和杆臂轨迹。因此“ATE 变了而 RPE 没变”或相反，都要结合误差作用位置解释。

### 2.4 阈值指标会放大小变化

连续误差只改变少量，阈值成功率仍可能明显跳变。若许多样本集中在 0.5 m 附近，参考改变几厘米就可能让一批样本同时跨过 0.5 m 成功线。成功率变化大不一定表示连续误差同幅度恶化；应同时查看误差分布、阈值曲线和逐帧配对变化。

ICP overlap、点云残差和正反一致性可以支持跨序列世界注册，但它们不是相机 Pose 的绝对误差上界。相机参考还包含 LIO 轨迹、外参、整流和时间链，详见[点云配准](../fundamentals/点云配准.md)与参考位姿篇。

## 3. 两类敏感性实验回答不同问题

“扰动参考”至少有两种实验。它们改变的分支不同，不能用成本较低的第一类替代第二类。

### 3.1 A 类：固定预测，只扰动评分参考

固定以下制品：

- Reference 视觉地图；
- 每种方法的 raw prediction；
- 接受/拒绝状态和接受阈值；
- 图像集合及其他算法输出。

只改变 Query 评分参考，再运行同一评分器。它回答：

> 现有预测和方法比较对评分参考的设定有多敏感？

这类实验适合快速扫描外参、时间、世界注册候选或局部参考扰动。若改变时间，需要重新做时间关联和轨迹插值，而不是把同一行 Pose 改一个时间戳。越界、超出最大插值间隔和无法获得参考的帧应显式记录。

### 3.2 B 类：扰动 Reference 几何并重建定位链

若参考参数也参与 Reference 相机 Pose 或建图，完整实验需要：

1. 修改相应的固定相机 Pose 或共享参数；
2. 重新三角化 observation、track 和 landmark；
3. 重新运行检索后的关联、PnP 与接受判断；
4. 用同一场景定义下的 Query 参考重新评分。

它回答：

> 参考几何变化会怎样影响地图、预测、接受覆盖和最终评分？

A 类能显示评分端的敏感性，却看不到地图点、track、PnP 内点和接受状态随 Reference 几何变化的结果，所以不能替代 B 类。B 类成本更高，适合在 A 类发现关键因素后选择少量代表场景端到端验证。

### 3.3 共享参数要按依赖关系一起变化

如果同一个真实外参或时间参数同时用于 Reference 建图和 Query 参考，它的扰动应沿实际依赖图作用于两侧。把本应共享的物理参数在两侧独立随机采样，会制造系统中不存在的差异；把本来每次安装独立的参数强制共变，也会低估风险。

实验首先要说明参数是全局共享、逐设备、逐安装批次、逐序列常量，还是随时间变化，再决定联合场景。相关性来自系统结构和校验证据，不应为了让蒙特卡洛方便而假设各项天然独立。

## 4. 如何设计可解释的补测

### 4.1 从冻结基线开始

先复现冻结基线，并保存预测、接受状态、参考版本、有效样本、评分器版本和逐帧输出。零扰动场景必须逐项复现基线；若零扰动都不一致，应先解决实现或制品身份问题。

每个扰动参数至少写清：

- 它表示哪个物理量，作用在哪条分支；
- 使用哪个坐标系、左乘还是右乘；
- 平移、角度和时间的单位；
- 扰动范围来自标定重复性、时间语义、注册候选还是纯教学假设。

扰动幅度没有跨设备通用标准。若只是探索性扫描，要称为“所测试的假设范围”，不能包装成设备置信区间。

### 4.2 先单因素，再做有依据的组合

先对一个参数做正负方向或离散候选扫描，观察响应是否平滑、是否存在阈值跳变和样本变化。随后只组合有物理依据、可能共同出现的少量场景，避免无边界的参数排列组合让结果无法解释。

所有方法必须使用同一组参考场景。对每个场景同时比较：

- 各方法的连续误差与阈值指标；
- 方法两两差距，而不只看名次；
- 排名是否变化、变化发生在哪些序列或区域；
- accepted、solver output 和有效参考覆盖是否变化；
- 逐帧新增成功、退化和共同失败。

最后再挑选对结论影响最大的代表场景做 B 类端到端重建。选择场景应依据参考不确定性和 A 类结果，不得依据“哪个场景让某个被测方法最好”。

### 4.3 固定共同样本，同时报告覆盖

时间扰动或参考有效范围变化可能改变 eligible mask。主要方法比较应使用各参考场景之间的共同有效样本，避免“困难帧恰好失去参考”造成虚假提升；同时另报每个场景的有效样本数和覆盖率，不能让共同子集掩盖参考大量失效。

若方法预测覆盖不同，还要区分：固定输入集合、具有参考的集合、具有 solver output 的集合和 accepted 集合。指标分母的定义仍以[定位评估方法](./定位评估方法.md)为准。

参考估计数据、候选筛选数据和算法评分数据的职责应分开。禁止读取被测视觉方法误差后，反向挑选最有利的世界变换、外参或时间偏移；这会把测试结果泄漏进参考。

## 5. 连续小误差与离散错误候选

外参的小平移或小角度偏差可以在名义值附近用切空间扰动观察。例如明确采用左扰动时：

$$
T'=\exp(\delta\xi^\wedge)T.
$$

这种局部扫描适合描述“参数附近的小变化如何传播”。但 ICP 落入另一个房间、楼层或重复走廊，是**离散候选歧义**：另一种解释可能离当前解很远，中间区域反而残差更大。单个 ICP 解附近的 Hessian 或局部协方差无法充分表示另一个孤立候选。

处理离散歧义时，可以：

- 从不同位置和朝向提出多个独立初值；
- 分区域检查双侧重叠与残差覆盖，避免单一区域主导；
- 留出未参与配准的空间区域进行验证；
- 在局部时间窗口或路线片段上检查同一世界变换是否一致；
- 若候选仍不可区分，保留多假设或拒绝冻结。

这些检查提供内部稳定性和留出泛化证据，仍不等于独立真值验证。多初值都选中同一错误重复结构，或者留出区域具有同样的重复性，依然可能得到一致但错误的结果。

## 6. 怎样判断算法结论是否稳定

对方法 m 和参考场景 s，记某个“越大越好”的指标为 $M_m(s)$。方法 A 相对 B 的差距是：

$$
\Delta_{A,B}(s)=M_A(s)-M_B(s).
$$

只看排名会丢掉差距大小。$\Delta$ 在不同场景中始终同号且有实际任务意义，比“名次没有变”提供更多信息；若差距很小，极少量阈值翻转就可能换名次。反过来，即使排名不变，所有方法的绝对误差或覆盖也可能显著恶化。

稳定性分析至少应问：

- 方法间实际差距多大，是否只在小数点或少数帧上领先；
- 结论是否在不同序列、区域和参考场景中一致；
- 连续误差、阈值成功率和危险接受是否同步变化；
- 排名反转是否集中在阈值附近的小差距；
- 某种方法是否对时间、外参或世界注册特别敏感；
- 扰动是否改变有效样本、solver output 或 accepted 覆盖。

下面是**虚构教学示例**。假设两种方法的预测和接受状态完全固定，只替换评分参考；数值仅用于演示，不代表任何设备精度或实测结果：

| 参考场景 | A 中位位置误差 | B 中位位置误差 | A 成功率 | B 成功率 | 按中位误差排序 |
| --- | ---: | ---: | ---: | ---: | --- |
| 名义参考 | 0.21 m | 0.23 m | 78% | 74% | A 优于 B |
| 假设参考扰动 | 0.24 m | 0.22 m | 69% | 76% | B 优于 A |

这个表只能说明：在所测试的两个参考场景中，A/B 的相对结论不稳定。它不能告诉我们哪个参考更接近真实位姿，也不能证明 B 无条件优于 A。可靠表述应是“在所测试的参数范围和场景中稳定/不稳定”，而不是发明“差距大于某个倍数就一定可靠”的通用判据。

## 7. 敏感性、不确定性与准确性不是同一层证据

| 层次 | 回答的问题 | 不能自动推出 |
| --- | --- | --- |
| 实现检查 | 代码是否按坐标、单位和公式约定计算 | 输入参数真实、结果准确 |
| 内部一致性 | 正反、重放、约束和数据是否自洽 | 相对外部世界正确 |
| 敏感性分析 | 输入在给定范围变化时，指标和结论怎样变化 | 这些范围具有概率含义 |
| 不确定性量化 | 有依据的随机误差模型怎样传播到输出分布 | 模型覆盖所有偏差和离散错误 |
| 独立准确性验证 | 与独立测量相比，结果有多接近真实 | 超出验证范围仍同样准确 |

### 7.1 一阶传播及参数相关性

若输出 $y=f(x)$，在名义点附近的一阶传播为：

$$
\Sigma_{out}\approx J\Sigma_{input}J^{\mathsf T}.
$$

对位姿，扰动和协方差应定义在声明的切空间中。若 $x$ 同时包含外参、时间和世界注册参数，$\Sigma_{input}$ 的非对角交叉项描述它们的相关性；把联合协方差强行改成块对角，相当于额外假设参数独立。

一阶传播适合局部、近似光滑的变化，不能表示错误房间这类离散候选，也可能在线性化范围过大时失真。假设的扰动区间本身不是置信区间；只有输入分布、相关性和模型都有证据时，随机采样得到的分位数才可能获得相应概率解释。

### 7.2 Bootstrap 的相关性边界

点云中的相邻点共享表面、扫描姿态和系统偏差，视频相邻帧也高度相关。逐点或逐帧独立 bootstrap 会夸大有效样本量。按扫描、时间窗口、空间块或完整序列分块重采样更符合相关结构，但得到的仍是**该分块采样流程下的统计稳定性**，不会自动成为相机绝对位姿的置信区间。

## 8. 可复用的实验记录模板

| 字段 | 记录内容 |
| --- | --- |
| 参考版本 | 生成代码、输入身份、坐标/时间约定与资格等级 |
| 扰动依据 | 参数来源、范围或离散候选，以及是否具有概率含义 |
| 作用分支 | 仅 Query 评分参考，或 Reference 建图 + 定位 + 评分 |
| 固定项 | 地图、预测、接受状态、阈值、评分器及随机种子 |
| 有效样本 | $N_{all}$、各场景 $N_{eval}$、共同有效集合与覆盖率 |
| 指标变化 | 连续误差、阈值成功、危险接受及逐帧变化 |
| 方法差距 | 两两差距、排序变化、按序列/区域的异质性 |
| 结论范围 | 仅在何种参数、场景、样本和参考资格下成立 |

这份记录把“改变了什么”和“结论能说到哪里”放在一起，便于将探索性敏感性分析与正式不确定性或准确性声明分开。

- Zhang 与 Scaramuzza，[A Tutorial on Quantitative Trajectory Evaluation for Visual(-Inertial) Odometry](https://rpg.ifi.uzh.ch/docs/IROS18_Zhang.pdf)，IROS 2018：适合核对轨迹对齐自由度、ATE/RPE 定义及可复现评价方式。
- Barfoot 与 Furgale，[Associating Uncertainty With Three-Dimensional Poses for Use in Estimation Problems](https://doi.org/10.1109/TRO.2014.2298059)，T-RO 2014：适合学习如何用指数映射把不确定性关联到三维位姿，并进行复合与传播。
- Brossard、Bonnabel 与 Barrau，[A New Approach to 3D ICP Covariance Estimation](https://doi.org/10.1109/LRA.2020.2965391)，RA-L 2020：适合理解 ICP 输出不确定性为何与初始化、退化和传感器误差模型有关。
