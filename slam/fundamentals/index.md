# 基础原理

从视觉感知建立对应，经过相机几何与点云空间关系，再进入地图组织、状态估计和多传感器标定。建议按以下顺序阅读：

1. [视觉地点识别与图像匹配](./视觉地点识别与图像匹配.md)
2. [从图像对应到相机位姿](./从图像对应到相机位姿.md)
3. [点云配准](./点云配准.md)
4. [地图到底存了什么](./地图到底存了什么.md)
5. [状态估计与不确定性](./状态估计与不确定性.md)
6. [多传感器时空标定](./多传感器时空标定.md)

其中“点云配准”主讲不同点云坐标系之间的刚体对齐；传感器安装与时间关系仍由“多传感器时空标定”主讲。
