# 基础原理

从视觉感知建立对应，经过相机几何与点云空间关系，再进入地图组织、状态估计、回环和多传感器标定。建议按以下顺序阅读：

1. [视觉地点识别与图像匹配](./视觉地点识别与图像匹配.md)
2. [从图像对应到相机位姿](./从图像对应到相机位姿.md)
3. [点云配准](./点云配准.md)
4. [地图到底存了什么](./地图到底存了什么.md)
5. [状态估计与不确定性](./状态估计与不确定性.md)
6. [回环检测与位姿图优化](./回环检测与位姿图优化.md)
7. [多传感器时空标定](./多传感器时空标定.md)

其中“点云配准”主讲不同点云坐标系之间的刚体对齐；“回环检测与位姿图优化”连接地点识别、几何验证与全局图约束；传感器安装与时间关系仍由“多传感器时空标定”主讲。具体实现分别放在 [OpenVINS](../openvins/)、[SfM 与 COLMAP](../colmap/)和 [RTAB-Map](../rtabmap/)专题中：依次连接 VIO 滤波、离线稀疏重建，以及在线地图、回环与长期记忆。
