# RTAB-Map

本专题沿公开源码整理 RTAB-Map 的视觉前端、地图记忆、定位链和误接受边界；OpenVINS 作为独立 VIO 框架，只在外部 odometry 接口处衔接。

## 阅读顺序

1. [地图与记忆管理](./地图与记忆管理.md)：理解 `SensorData`、`Signature`、约束与 STM/WM/LTM。
2. [视觉前端、跟踪与深度来源](./视觉前端、跟踪与深度来源.md)：区分时间跟踪、双目对应、稀疏 3D 与整图深度。
3. [建图过程与地图更新](./建图过程与地图更新.md)：追踪节点、稀疏几何、数据库和派生地图的更新。
4. [里程计与外部 VIO](./里程计与外部VIO.md)：分清局部连续运动与全局地图校正。
5. [OpenVINS：状态传播与视觉更新](./OpenVINS状态传播与视觉更新.md)：学习独立 VIO 的 IMU 传播、MSCKF 更新与接口边界。
6. [定位与重定位流程](./定位与重定位流程.md)：从地点候选、度量注册到 `map→odom`。
7. [危险误接受防护与恢复](./危险误接受防护与恢复.md)：理解接受前验证、后端抑制和接受后恢复。
8. [RTAB-Map 与 HLoc 的定位链对比](./RTAB-Map与HLoc的定位链对比.md)：比较两类地图、候选、几何和输出契约。

通用对应、几何、地图与图优化原理见[基础原理](../fundamentals/)；系统状态机与异步接口见 [Robotics Systems](../../robotics-systems/)。
